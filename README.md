# Portfolio professionnel — Koffi Romeo

Site statique prêt pour GitHub Pages.

## Fichiers
- `index.html` : contenu du portfolio
- `style.css` : design responsive
- `script.js` : menu mobile, animations, année automatique

## Personnalisation à faire avant publication finale
1. Remplacer `votre-email@exemple.com` dans `index.html` par votre adresse professionnelle.
2. Ajouter votre numéro de téléphone et votre profil LinkedIn dans la section Contact.
3. Remplacer les visuels abstraits des projets par vos cartes originales exportées en JPG/PNG/WebP.
4. Ajouter votre CV PDF dans `assets/cv/` puis créer un bouton vers ce fichier.
5. Affiner les dates et intitulés de la section Parcours à partir du CV définitif.

## Publication sur GitHub Pages
Copiez `index.html`, `style.css`, `script.js` et le dossier `assets/` à la racine du dépôt `koffiromeo.github.io`.
